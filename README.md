# FaqrAi – vydání a daňové parametry

Veřejný repozitář s hotovými instalačkami programů **FaqrAi** (malé firmy) a **FaqrAi Simple** (OSVČ)
a s podepsaným souborem daňových parametrů.

- **Stažení programu:** sekce *Releases* vpravo. Windows: `FaqrAi-…-Windows-x64.exe` nebo
  `FaqrAi-Simple-…-Windows-x64.exe`; macOS: `…-macOS-arm64.zip` (Apple Silicon) nebo `…-x64.zip` (Intel).
- **Automatické aktualizace:** nainstalovaný program si nové verze stahuje odtud sám
  (Nastavení → Aktualizace programu).
- **`odvolane.json`:** podepsaný seznam licencí zneplatněných vydavatelem (jen čísla licencí).
- **`parametry.json`:** sazby DPH, limity a parametry daní OSVČ. Program si je stahuje a přijme jen
  s platným podpisem vydavatele; ruční úprava souboru podpis zneplatní.

Zdrojový kód je v soukromém repozitáři. Poskytovatel: Pavel Vítek, pavel.vitek16@gmail.com.
