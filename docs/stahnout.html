Ke stažení

Zkušební verze na dní, plná, bez omezení. Máte licenci? Zadejte ji v instalátoru – nainstaluje se verze, ke které licence patří. Po zadání licence data zůstanou a program se dál aktualizuje sám podle licence.

Načítám seznam verzí…

Windows

Stáhněte malý instalátor (…-Setup.exe, asi 0,5 MB). Zeptá se na licenci (u dřívější instalace ji převezme sám), podle ní vybere verzi – bez licence nejnovější zkušební –, stáhne ji, ověří kontrolní součet a nainstaluje. Plná instalačka se hodí pro počítač bez internetu. Instalačka zatím není podepsaná certifikátem, Windows SmartScreen proto ukáže varování: klikněte na Další informace → Přesto spustit. Kdyby malý instalátor zablokoval antivirus, stáhněte plnou instalačku – licenci pak zadáte v programu a ten si sám stáhne verzi, ke které patří. Při spuštění nad existující instalací nabídne Aktualizovat / Opravit / Odstranit. Data uživatele se při odinstalaci nikdy nemažou.

macOS

Stáhněte ZIP pro svůj procesor (Apple Silicon = M1 a novější, Intel = starší Macy), rozbalte a přetáhněte aplikaci do složky Aplikace. Při prvním spuštění klikněte pravým tlačítkem → Otevřít → Otevřít. Hlásí-li macOS, že je aplikace poškozená, spusťte v Terminálu: xattr -cr "/Applications/FaqrAi.app" (resp. „FaqrAi Simple.app“).
