Ke stažení

Zkušební verze na dní, plná, bez omezení. Po zadání licenčního klíče data zůstanou. Program se dál aktualizuje sám.

Načítám seznam verzí…

Windows

Spusťte stažený .exe. Instalačka zatím není podepsaná certifikátem, Windows SmartScreen proto ukáže varování: klikněte na Další informace → Přesto spustit. Při spuštění nad existující instalací nabídne Aktualizovat / Opravit / Odstranit. Data uživatele se při odinstalaci nikdy nemažou.

macOS

Stáhněte ZIP pro svůj procesor (Apple Silicon = M1 a novější, Intel = starší Macy), rozbalte a přetáhněte aplikaci do složky Aplikace. Při prvním spuštění klikněte pravým tlačítkem → Otevřít → Otevřít. Hlásí-li macOS, že je aplikace poškozená, spusťte v Terminálu: xattr -cr "/Applications/FaqrAi.app" (resp. „FaqrAi Simple.app“).
